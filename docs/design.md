# Astravon DSL — Design & Philosophy

Astravon DSL is built for secure, domain-specific computation across AI, blockchain,
biotech, and simulation domains. Core principles:

- **Security-first**: Code is verifiable and sandboxed by default.
- **Multi-domain primitives**: AI, DNA, chain, and realm built-in.
- **Portability**: Runs on Astravon Virtual Machine (AVM) targeting LLVM/WASM.
- **Simplicity**: Syntax is minimal but powerful, like a blend of Rust and Python.
